# 📝 Blogicum

Blogicum — учебная блог-платформа на Django.

В этой версии проекта была реализована работа с базой данных, моделями Django ORM и административной панелью.

---

# Цель проекта

Основная задача заключалась в переходе от хранения данных в Python-структурах к полноценной работе с базой данных через Django ORM.

В ходе проекта были изучены:

* модели Django;
* связи между моделями;
* Django ORM;
* миграции;
* административная панель;
* работа с базой данных SQLite;
* фильтрация данных через QuerySet;
* получение данных из базы и отображение их в шаблонах.

---

# ✅ Что реализовано

### Модели данных

Созданы модели:

* публикация (`Post`);
* категория (`Category`);
* местоположение (`Location`).

Для публикаций реализованы связи с:

* пользователями;
* категориями;
* местоположениями.

### Административная панель

Настроена админ-панель Django:

* управление публикациями;
* управление категориями;
* управление местоположениями;
* русификация моделей и полей;
* отображение удобных названий и подсказок.

### Работа с публикациями

Реализован вывод публикаций из базы данных:

* на главной странице;
* на странице категории;
* на странице отдельной публикации.

Публикации отображаются только если:

* дата публикации не позже текущего времени;
* публикация опубликована;
* категория опубликована.

### Работа с категориями

Для каждой категории реализована отдельная страница.

Если категория снята с публикации, пользователь получает ошибку 404.

### Оптимизация структуры проекта

* подключены модели Django;
* настроены миграции;
* загружены тестовые данные через фикстуры;
* организована работа через ORM вместо словарей и заглушек.

# ⚙️ Установка проекта

### Клонирование репозитория

```bash
git clone https://github.com/VirentLilium/django-sprint3.git
cd django-sprint3
```

### Создание виртуального окружения

```bash
python -m venv venv
```

### Активация виртуального окружения

Windows:

```bash
venv\Scripts\activate
```

Linux / macOS:

```bash
source venv/bin/activate
```

### Обновление менеджера пакетов

```bash
python -m pip install --upgrade pip
```

### Установка зависимостей

```bash
pip install -r requirements.txt
```

# Запуск проекта

Перейдите в директорию Django-проекта:

```bash
cd blogicum
```

Примените миграции:

```bash
python manage.py migrate
```

Создайте суперпользователя:

```bash
python manage.py createsuperuser
```

Запустите сервер разработки:

```bash
python manage.py runserver
```

После запуска проект будет доступен по адресу:

```text
http://127.0.0.1:8000/
```
